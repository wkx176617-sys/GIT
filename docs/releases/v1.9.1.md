# v1.9.1 版本说明

发布日期：2026-08-13

## 版本目标

收紧 v1.9.0 升级路径的安全和发布边界：网络异常要有限等待，危险恢复要明确确认，公开教程
只保留一条推荐命令，并用完整流程测试证明升级不会改变节点身份、端口、用户名或密码。

## 修复与完善

- 稳定标签查询最多等待 20 秒，版本下载最多等待 120 秒；失败时不进入安装。
- GOST 下载增加 10 秒连接超时和 120 秒总超时，仍须通过固定 SHA-256 校验。
- BBR 插件升至 `1.1.1`；`bbrctl restore` 和卸载默认要求交互口令，`--yes` 仅供插件内部
  已确认流程使用。
- 早期节点首次引入升级器仍可使用独立脚本；安装完成后唯一推荐入口为
  `socksctl version` 和 `socksctl upgrade`。
- README 不再复制 macOS、Windows 平台命令，平台教程继续作为唯一安装命令来源。
- 新增隔离临时目录中的完整升级流程测试，实际执行标签检查、下载、安装调用和升级后验收。
- 隐私扫描新增私钥头、常见 Token、带凭据代理链接和敏感密钥文件名检查。
- CI 强制运行 ShellCheck；标签校验通过后按本版本说明自动创建 GitHub Release。

## 复杂度与性能影响

- 常驻进程：无新增，GOST 仍是唯一必要的常驻业务进程。
- 网络端口：无新增。
- 定时任务：无新增。
- 依赖：Ubuntu 升级路径明确使用系统自带 coreutils `timeout`；不增加常驻依赖。
- 用户步骤：首次引入升级器的步骤不变；以后只使用 `socksctl upgrade`，公开入口更少。
- 运行性能：无持续影响；超时、隐私扫描和完整流程测试只在人工调用或 CI 中运行。
- 外部访问：仍只在人工安装或升级时访问固定 GitHub 资源，并加入有限等待。
- 模块耦合：没有新增后台模块；测试使用全自定义临时路径，不访问生产配置。
- BBR 插件 1.1.1 保持独立可选，主程序不自动调用。

## 兼容性与升级

兼容 v1.9.0 及可被现有升级器识别的更早本项目节点。升级继续保留节点名称、IP记录、端口、
用户名和密码，因此比特浏览器代理资料无需修改。独立 `socks-upgrade` 命令不会删除，已有自动化
仍可工作；文档只把 `socksctl upgrade` 作为推荐入口。

升级会重启一次 GOST，现有连接可能短暂中断。标签查询或下载超时会在安装前停止，不改变服务。

## 回退

升级前仍创建事务快照，升级后身份或版本验收失败会触发现有回退。升级器不允许降级；确需回退
时先运行 `socksctl report` 保留脱敏现场，再按目标版本说明人工评估。已发布标签不可移动。
