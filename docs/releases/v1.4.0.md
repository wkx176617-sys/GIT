# v1.4.0 版本说明

发布日期：2026-08-12

状态：当前推荐稳定版

## 为什么需要本版本

使用新代码不会让服务器公网 IP 本身产生冲突。实际风险是旧 sing-box、x-ui、Xray、v2ray
或其他程序仍占用相同端口，或者新安装意外更换了原 SOCKS5 账号密码。本版本增加安装前
质检和受控覆写，把“检查”和“修改”明确分开。

## 新增功能

- `preflight.sh` 只读检查系统镜像、架构、systemd、必要命令、常见代理服务和目标端口。
- 标准 Mac 部署与 Windows/Xshell 安装均先质检，未通过时不会继续普通安装。
- `overwrite.sh` 仅支持配置可解析、端口吻合且含有效账号密码的旧 sing-box SOCKS5。
- 覆写前备份 `/etc/sing-box`、systemd 服务定义和启用状态到
  `/root/gost-socks-backups/时间戳/`。
- 迁移时保留旧端口、用户名和密码；安装后自动验证代理出口，失败时停止新 GOST 并尝试
  恢复旧 sing-box。
- x-ui、Xray、v2ray 和未知进程不会被自动停用或删除。

## Ubuntu 镜像兼容范围

- Ubuntu 20.04 LTS、22.04 LTS、24.04 LTS。
- `amd64` 与 `arm64`。
- 使用 systemd 的标准镜像以及常见精简镜像；Xshell 入口会补齐所需软件包。
- Debian、CentOS、AlmaLinux、Rocky Linux 等暂不声明支持，待有真实镜像后单独测试和增加。

## 新安装

```bash
bash xshell-install.sh --port 31080
```

## 旧 sing-box 覆写

先只读质检：

```bash
bash preflight.sh --port 31080
```

只有报告明确显示“可迁移”时执行：

```bash
bash xshell-install.sh --port 31080 --overwrite
```

## 从 v1.3.0 升级

已经由本工具运行 GOST 的节点直接重新运行标准安装即可，原节点名称、端口和凭据会保留。
仍在运行旧 sing-box 的节点使用上面的质检和覆写流程。

## 回退

可以切换回 `v1.3.0`。如果本版本已成功从 sing-box 切换到 GOST，回退仓库代码不会自动
恢复 sing-box；旧文件仍位于 `/root/gost-socks-backups/`，需要人工确认后再恢复，避免两个
服务重新争抢同一个端口。

## 已知限制

- 只自动迁移 `/etc/sing-box/config.json` 中恰好一个匹配端口、类型为 `socks`、且首个用户
  包含兼容用户名和密码的入站。
- 不迁移 sing-box 的其他入站、出站和路由规则。
- 不自动修改萤光云安全组。
- 无法安全识别的旧服务必须人工分析，不提供“强制全部停止”选项。
