# v1.9.3 版本说明

发布日期：2026-08-14

## 版本目标

把已有节点升级的推荐步骤收敛为一条命令，同时保留 v1.9.2 已验证的只读预检、人工确认、事务
快照、失败回退和凭据不变验收。减少重复输入，避免用户在 `--check` 与正式命令之间填错版本或路径。

## 主要变化

- 已安装升级器的节点只需运行 `socksctl upgrade v目标版本号`。
- 正式命令会先自动检查节点身份、版本方向、保留端口和 GitHub 稳定标签，再请求人工确认。
- `socksctl upgrade --check v目标版本号` 继续兼容，定位调整为可选的提前体检。
- 没有永久升级命令的早期节点，在固定标签源码准备完成后只执行一次正式升级命令。
- 命令帮助先展示唯一推荐路径；高级兼容入口放在其后，避免形成两套主流程。
- 发布门禁和完整流程测试共同验证“同一条正式命令先预检、后确认、再升级”。

## 安全与兼容

升级范围没有扩大：只接受已经由本项目管理的节点和高于当前版本的完整稳定标签，不负责首次
安装、降级或其他代理迁移。升级仍强制核对节点名称、IP记录、端口、用户名和密码；任一项意外
变化都会失败并按事务规则回退。升级会重启一次 GOST，现有连接可能短暂中断，但比特浏览器中
保存的代理用户名和密码不需要修改。

## 复杂度与性能影响

- 常驻进程：无新增，GOST 仍是唯一必要的常驻业务进程。
- 网络端口：无新增。
- 定时任务：无新增。
- 依赖：无新增；仍只使用升级模块已有的 git、timeout 和安装器依赖。
- 用户步骤：已安装节点从“只读检查后再正式升级”收敛为一条正式命令。
- 运行开销：无后台开销；只读检查仍仅在人工调用升级时运行一次。
- 模块耦合：未新增模块或跨模块调度，只调整升级器帮助、唯一升级专题和发布门禁。
- BBR 插件 1.1.1 未修改，继续独立可选。

## 回退

本补丁没有改变配置、快照格式或恢复流程。升级失败继续使用现有事务快照回退；需要人工回退时，
按版本说明和 `socksctl recover` 的现有流程处理，不通过升级命令执行降级。
