# v1.7.6 版本说明

发布日期：2026-08-13

## 版本目标

把 GitHub 首页从偏工程仪表盘的展示，调整为轻盈、温和、有留白的 Instagram 编辑风格，
同时保持新手单一主路径、无障碍文字说明和技术信息可查询。

## 视觉更新

- 新增原创 3:1 横幅，使用奶油白、雾粉、鼠尾草绿和少量香槟金。
- 横幅通过设备、安全云节点和柔和连接线表达项目用途，不使用文字、品牌或复杂 UI。
- 徽章改为低饱和扁平配色，减少蓝色工程面板感。
- 标题、短句、导航和段落增加留白，语言更温和直接。
- 图片带有中文替代文字，无法加载图片时仍可理解内容。

## 信息架构

- 首页主要入口收敛为开始搭建、日常使用、可选插件和遇到问题。
- 平台选择保留在简洁表格中，安装细节按需展开。
- 模块结构、维护和版本资料放入折叠区域，不占据新手首次阅读主线。
- 重要安全边界保持直接可见，不因视觉精简被隐藏。
- 新增视觉与文案规范，统一配色、页面层级、语气、图片预算和无障碍要求。

## 复杂度与性能影响

- 常驻进程：无新增。
- 网络端口：无新增。
- 定时任务：无新增。
- 服务器依赖：无新增。
- 服务器运行逻辑：仅版本号变化。
- GitHub资源：新增约124KB的本地JPEG横幅，不使用外部字体或前端脚本。
- 用户步骤：无新增。
- 模块耦合：无新增。
- BBR 插件 1.1.0 保持独立可选，主程序不自动调用。

## 兼容性与升级

完全兼容 v1.7.5 和 v1.6.x 的命令、配置、凭据、快照、报告与插件。已有服务器无需为了
README视觉变化重新部署。

## 回退

本版本不改变服务器行为，通常无需回退。如需查看旧首页布局可切换 v1.7.5；服务器节点无需
做任何变更。
