# v1.7.0 版本说明

发布日期：2026-08-13

## 版本目标

本版本不继续堆叠运行功能，而是正式建立项目的长期方向：新手防呆、模块化扩展、稳定轻量、
步骤少且教程完整，问题可记录复盘，同时用明确边界阻止代码和运行架构过度膨胀。

## 主要变化

- 新增《项目宗旨与开发边界》，定义六项核心原则、性能预算和新功能准入问题。
- 新增《轻量模块架构》，明确 GOST、安装入口、`socksctl`、诊断、安全工具和插件的职责。
- 发布流程要求每个版本说明复杂度与性能影响。
- 非必要功能默认插件优先，插件不得被主安装程序自动启用。
- 明确 `v2.0.0` 只用于无法兼容迁移的重大架构变化，避免为宣传虚升主版本。

## 复杂度与性能影响

- 常驻进程：无新增，仍只有 GOST 作为必要业务进程。
- 网络端口：无新增，仍默认只使用 `31080/TCP`；SSH 由系统提供。
- 定时任务：无新增，不安装 cron 或 systemd timer。
- 数据库与面板：无新增。
- 运行依赖：无新增。
- 用户步骤：安装和日常使用步骤不增加，仍推荐 `socksctl guide`。
- 模块耦合：无新增；本次只固化边界、文档和发布检查。
- Mac/Windows 性能：无后台进程，仅在用户主动使用 SSH/Xshell 时工作。

## 兼容性

- 完全兼容 `v1.6.2` 的节点配置、命令、快照和报告。
- Ubuntu 20.04、22.04、24.04。
- `amd64`、`arm64`。
- GOST `3.2.6`。
- BBR 插件 1.1.0，继续作为独立可选插件。

## 升级

切换到 `v1.7.0` 并重新执行原安装入口。已有端口、名称、账号、密码和健康快照会被保留。
升级后运行：

```bash
socksctl doctor --no-record
socksctl guide
```

## 回退

本版本没有改变运行配置格式。需要回退时可切换到 `v1.6.2`，并按照降级保护提示添加明确的
降级参数和交互确认。回退前先运行 `socksctl report` 保存现场。

## 已知限制

- 项目仍定位为单台 VPS 上的轻量 SOCKS5 工具，不提供集中节点管理平台。
- IPv6、DNS、WebRTC 和时区仍需在真实客户端及比特浏览器内人工验收。
- 文档规则不能替代真实节点验证，后续版本仍应以实际重复问题为升级依据。
