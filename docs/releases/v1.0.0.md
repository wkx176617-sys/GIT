# v1.0.0 版本说明

发布日期：2026-08-11

状态：历史稳定版

## 内容

- 首次提供 macOS 到 Linux VPS 的 SSH/SCP 部署流程。
- 默认统一使用 `31080/TCP`。
- 固定 GOST 3.2.6，并校验官方 SHA-256。
- 提供安装、卸载、检查、日志、重启和密码轮换命令。

## 适用范围

适合只从 macOS 管理节点的环境。Windows/Xshell 用户应使用 `v1.1.0` 或更高版本。

## 已知限制

- 没有 Windows + Xshell 专用入口。
- 尚未建立强制的版本说明和发布检查制度。
