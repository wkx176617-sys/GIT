# v1.2.0 版本说明

发布日期：2026-08-11

状态：历史稳定版

## 新增

- 完整的跨平台搭建、验收、维护、升级和回退教程。
- 工具版本与 GOST 核心版本的明确区分。
- 每个历史稳定版本的独立说明文件。
- 固定的版本维护与发布规则。
- GitHub Actions 自动执行语法和版本资料完整性检查。
- 本地 `release-check.sh` 发布前检查入口。

## 兼容性

- 与 `v1.1.0` 的安装命令和服务器配置兼容。
- GOST 仍固定为 3.2.6。
- 新服务器推荐 Ubuntu 24.04 LTS；现有 Ubuntu 22.04 LTS 节点继续兼容。
- 默认端口仍为 `31080/TCP`。
- 不会自动修改云安全组或删除旧代理服务。

## 升级

已经使用 `v1.1.0` 成功部署的节点不必立即重装。本版本主要完善教程和维护制度；新节点应直接使用 `v1.2.0`。

## 回退

如需回退文档和脚本，可切换到 `v1.1.0`。现有服务器节点无需随文档回退。

## 固定源码

发布后可通过 `https://github.com/wkx176617-sys/GIT/tree/v1.2.0` 查看。
