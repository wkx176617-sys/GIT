# v1.12.2：智能迁移发布修正

发布日期：2026-08-14

本版本完整包含 v1.12.1 的单命令智能迁移、旧 sing-box 停用、代理凭据轮换、GOST 独占端口
验收和失败回退。它仅修正迁移确认提示中的端口格式占位符，使 ShellCheck 发布门禁通过。

`v1.12.1` 标签没有通过线上静态检查，因此未生成 GitHub Release。项目不重写已经推送的版本
标签，改用本补丁作为对外稳定版本。

## 复杂度与性能影响

| 项目 | v1.12.2 变化 |
|---|---|
| 常驻进程 | 无变化；迁移成功后只有 GOST |
| 业务/管理端口 | 无变化；不新增端口 |
| 定时任务 | 无 |
| 依赖 | 无新增 |
| 用户步骤 | 保持一条智能安装命令和一次迁移确认 |
| 凭据 | 本项目升级保留；旧协议迁移轮换 |
| 模块耦合 | 无新增；沿用 v1.12.1 的智能分流边界 |
| BBR/插件 | BBR + FQ 默认策略不变；插件中心继续为空 |

完整迁移条件、事务步骤和回退说明见 [v1.12.1 版本档案](v1.12.1.md)。
