# v1.7.3 版本说明

发布日期：2026-08-13

## 版本目标

完成文档层的模块化收口：Mac 用户进入 Mac 专用步骤，Windows 用户进入 Xshell 专用步骤，
客户端导入、二维码和网络验收由同一个专题统一维护；跨平台完整教程只负责串联全流程。

## 模块化审计结论

- GOST 仍是唯一常驻业务进程。
- `deploy.sh`、`xshell-install.sh` 和 `install.sh` 只承担部署生命周期。
- `socksctl` 保持为统一用户入口，诊断和安全状态分别交给 `socks-doctor`、`socks-safety`。
- BBR 仍位于 `addons/bbr/`，主安装、管理和诊断模块均不自动调用。
- 没有发现需要拆分的新运行模块；继续拆小会增加调用层级而没有实际收益。
- 文档层确认存在 Mac 入口不独立、客户端说明重复和发布检查未覆盖三个缺口，本版本已修复。

## 新增专题

- `docs/macos.md`：Mac Terminal 提示符、SSH测试、本地部署、先质检后迁移、查询和升级。
- `docs/clients.md`：一次查看全部连接方式、复制链接、二维码、v2rayN、小火箭、比特浏览器和验收。
- 首页、模块索引、架构说明、GitHub问题页和平台教程均链接到对应专题。

## 自动检查

发布检查现在要求 Mac、Windows、客户端专题同时存在，并确认：

- Mac 和 Windows 下载命令都固定到当前稳定标签；
- GitHub 首页提供 Mac 和客户端独立入口；
- 客户端专题包含复制链接和二维码命令；
- 全部 Markdown 本地链接指向存在的文件或目录。

## 复杂度与性能影响

- 常驻进程：无新增。
- 网络端口：无新增。
- 定时任务：无新增。
- 服务器依赖：无新增；二维码仍按需使用可选的 `qrencode`。
- 服务器运行逻辑：仅版本号变化，代理、诊断、恢复和插件逻辑不变。
- 用户步骤：没有增加强制步骤；Mac 用户减少无关内容，客户端说明集中到一个入口。
- 模块耦合：运行模块无变化，文档职责更清晰。
- BBR 插件 1.1.0 保持独立可选，主程序不自动调用。

## 兼容性与升级

完全兼容 v1.7.2 和 v1.6.x 的命令、配置、凭据、快照、报告及插件。已有节点无需为了文档
调整重新部署；新节点直接使用 v1.7.3 对应平台教程。

## 回退

本版本不改变服务器行为，通常无需回退。如需查看旧的文档布局可切换 v1.7.2；不建议继续
使用旧 Mac 入口，因为它会把新手带到跨平台完整 SOP。
