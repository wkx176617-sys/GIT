# v1.11.0 版本说明

发布日期：2026-08-14

## 版本目标

解决新手沿教程链路进入专题后难以返回、难以回到初始入口，以及知道关键词却找不到页面的问题。
保持第一次搭建只有一条推荐主线；返回、首页和搜索只作为辅助脱困入口，不把文档导航做成代理
管理面板，也不改变服务器安装、协议、端口、账号或密码。

## 导航与搜索

- 新手专题顶部和底部统一显示返回上一级、项目首页和快速搜索。
- 上一级由文档层级明确指定，不依赖不可预测的浏览器访问历史。
- 父级就是项目首页时合并重复链接，减少无意义选项。
- 新增 GitHub Pages 纯静态搜索页，支持中文关键词、分类筛选、方向键选择、回车打开和手机窄屏。
- 搜索默认只收录搭建、客户端、日常维护、故障和插件入口，不混入历史版本与维护者资料。
- 搜索在当前浏览器本地完成，不使用第三方搜索、外部字体、Cookie、统计或广告。

## 单一来源与失效回退

`docs/navigator/navigation.tsv` 是父级、分类、摘要、搜索词和推荐关系的唯一来源。
`scripts/docs-navigation --write` 根据清单生成每页导航区块和 `docs/navigation.md` 文字后备页；
维护者不在多个教程中手工复制导航。搜索页、JavaScript 或 GitHub Pages 暂时不可用时，GitHub
README、原有 Markdown 教程和文字导航仍可独立完成主流程。

发布门禁会检查导航 ID 与路径重复、未知父级、指向自身、文件缺失、生成内容漂移、静态脚本
语法、Pages 发布工作流和后备入口。新增新手教程必须先登记清单，避免出现无法进入或无法返回
的孤立页面。

## 规则符合性

本需求来自实际教程使用中的重复迷路问题。按仓库决策顺序，改动只发生在教程和公开文档层，
没有修改 GOST、安装事务、诊断、安全快照或日常管理命令。搜索是按需打开的静态页面，不适合
做插件，也不进入服务器核心。辅助导航不被标记为推荐下一步，首次搭建仍以
`docs/tutorial.md` 为唯一主线。

## 复杂度与性能影响

- 常驻进程：无新增，GOST 仍是唯一必要的常驻业务进程。
- 网络端口：VPS 无新增；没有 Web 管理端口。
- 定时任务：无新增。
- 服务器依赖：无新增。
- 维护依赖：导航生成器只使用 Python 3 标准库；静态页面不使用第三方前端包。
- 用户步骤：搭建步骤不增加；迷路时增加可选的返回、首页和搜索入口。
- 网络请求：打开搜索页时读取四个很小的静态文件；输入关键词不产生远端搜索请求。
- 数据与隐私：只索引公开教程，不读取、保存或发送 IP、用户名、密码、二维码和节点资料。
- 模块耦合：只新增公开文档工具与 GitHub Pages 工作流，不被安装器或 `socksctl` 调用。
- BBR 插件 1.1.1 未修改，继续独立可选。

## 回退与恢复

静态搜索发布失败不会影响 SOCKS5 服务或 Markdown 教程。用户可以直接回到 README 或
`docs/navigation.md`。如需回退本次文档交互，只需切换到上一稳定标签；服务器配置、凭据、
GOST 核心、快照和恢复格式与 v1.10.0 完全兼容。

已有健康节点无需为了使用网页导航而更新服务器；直接打开项目首页或快速搜索即可。只有需要让
服务器记录的工具版本同步到 v1.11.0 时才运行正常版本切换，切换仍会保留原端口、用户名和密码。
