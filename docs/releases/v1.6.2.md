# v1.6.2 版本说明

发布日期：2026-08-13

## 版本目标

进一步减少新手复制、粘贴和重复操作造成的风险，并补齐严格只读诊断、有限重试、恢复熔断、
快照完整性验证、降级保护和报告生命周期管理。

## 新手入口

安装完成后只需要记住：

```bash
socksctl guide
```

菜单只接受单个数字。无效输入不会执行操作；自动维修仍受白名单限制，手工恢复仍要求输入
`RESTORE`。Xshell 安装入口会拒绝多余参数，并提示不要把 `root@...#`、说明文字或网页提示符
一起粘贴。安装命令使用绝对路径，不要求用户先切换到正确文件夹。

## 诊断和重试边界

- `socksctl doctor --no-record` 严格只读，不写事件档案。
- 外部检测使用两个独立目标，每个最多两次。
- 同一目标两次检测之间等待 2 秒，单次最多等待 15 秒。
- GOST 服务每次重启间隔 5 秒，60 秒内最多启动 5 次。
- 达到上限后由 systemd 停止重启，程序只记录并转人工检查。

## 快照与恢复保护

- 新健康快照生成 SHA-256 清单。
- 恢复前检查必要文件、GOST 可执行文件、端口与凭据格式和文件校验值。
- v1.6.1 旧快照没有清单时只做兼容结构检查；成功升级后会换成带清单的新快照。
- 同一种白名单故障成功自动恢复一次后，30 分钟内再次出现会记录 `RECOVERY_LOOP` 并熔断。
- 熔断后保持当前状态，不执行第二次自动恢复。

## 安装与版本保护

- 修改前要求系统盘至少有 200MB 可用空间。
- 已存在的最后可用快照必须先通过检查。
- 检测到安装程序版本低于服务器现有版本时，默认阻止降级。
- 明确降级需要添加 `--allow-downgrade`，并在交互式终端输入 `DOWNGRADE`。

## 报告管理

```bash
socksctl report
socksctl reports
socksctl report-delete
```

服务器最多自动保留最近 5 份脱敏报告。删除全部报告需要输入 `DELETE-REPORTS`，删除后无法由
本工具恢复。报告仍包含 VPS 公网 IP 和服务日志，发送前必须人工检查。

## 兼容性

- Ubuntu 20.04、22.04、24.04
- `amd64`、`arm64`
- GOST `3.2.6`
- BBR 插件 1.1.0，仍为独立可选插件，主程序不会自动启用

## 升级后检查

```bash
socksctl doctor --no-record
socksctl snapshots
socksctl guide
```

检查通过后，再按照客户端与比特浏览器验收清单核对 IPv4、IPv6、DNS、WebRTC 和时区。
