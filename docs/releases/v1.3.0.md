# v1.3.0 版本说明

发布日期：2026-08-12

状态：当前推荐稳定版

## 新增功能

- `socksctl info` 同时显示服务器公网 IP、端口、用户名和服务状态，密码保持打码。
- `socksctl credentials` 显示完整的手工填写字段。
- `socksctl export` 一次显示手工字段、v2rayN 分享链接和 Shadowrocket 分享链接。
- `socksctl export v2rayn` 或 `socksctl export shadowrocket` 只输出指定客户端链接。
- `socksctl qr shadowrocket` 和 `socksctl qr v2rayn` 在 SSH/Xshell 终端本地生成二维码。

## 保存方式

真实节点配置只保存在对应服务器的 `/etc/gost-socks/node.env`，权限为 `0600`，只有 root
可以读取。本版本不创建 Mac/Windows 本地节点清单，也不会把节点信息同步到公开 GitHub。
在任意设备上登录对应服务器即可查询，但用户仍需保留 VPS IP 和 SSH 登录凭据。

## 客户端兼容性

- v2rayN 导出采用官方 `socks://` 分享格式，建议使用官方当前稳定版。
- Shadowrocket 同时导出 `socks5://用户名:密码@服务器:端口#名称` 链接和
  `节点名称=socks5,地址,端口,用户,密码` 文本配置，无法自动识别链接时可手工填写。
- 所有原有比特浏览器手工配置继续兼容。
- GOST 仍固定为 3.2.6，默认端口仍为 `31080/TCP`。

## 从 v1.2.1 升级

切换到本标签后重新运行原安装命令：

```bash
cd /root/socks5-toolkit
git fetch --tags
git switch --detach v1.3.0
bash xshell-install.sh --port 31080
```

升级会保留已有节点名称、端口、用户名和密码，同时补写公网 IP 并更新 `socksctl`。升级后运行：

```bash
socksctl info
socksctl export
```

## 回退

可切换回 `v1.2.1` 并重新运行安装入口。节点服务和凭据格式保持兼容；旧版 `socksctl` 不提供
客户端链接与二维码导出命令。

## 已知限制

- 每台服务器只保存自己的节点，不能在一台服务器中查看其他 VPS 的节点。
- 设备必须先通过 SSH/Xshell 登录服务器，才能查询完整密码。
- Shadowrocket 的商店版本会持续更新；无法识别链接时可使用 `socksctl credentials` 手工填写。
- 二维码包含明文连接凭据，应避免录屏、截图或使用在线二维码生成网站。
