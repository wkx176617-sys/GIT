# v1.8.1 版本说明

发布日期：2026-08-13

## 版本目标

修复重复使用早期服务器目录时，根目录遗留的旧 `socksctl` 可能遮挡新版
`scripts/socksctl`，造成“新版安装提示、旧版管理命令”的混装问题。

## 修复内容

- 安装器只接受当前标准目录 `scripts/` 内的管理、诊断、安全和换IP模块。
- 安装前对照 `VERSION` 与 `install.sh --version`，发现散落文件或混版立即停止。
- Xshell入口会明确显示验明的安装包版本和绝对目录。
- 安装完成摘要新增工具版本，便于截图时直接确认。
- 新手下载目录带版本号，避免旧目录残留文件参与新安装。
- 升级教程改为下载到新的版本目录，不再原地切换混有未知文件的目录。

## 复杂度与性能影响

- 常驻进程：无新增，仍只有GOST。
- 网络端口：无新增。
- 定时任务：无新增。
- 依赖：无新增。
- 用户步骤：安装命令数量不变，目录名增加稳定版本号。
- 运行性能：无影响；版本一致性检查只在人工安装时执行一次。
- 模块耦合：没有新增运行时耦合，只收紧安装包来源。
- BBR 插件 1.1.0 保持独立可选，主程序不自动调用。

## 兼容性与升级

完全保留已有端口、用户名、密码、节点配置、快照和事件记录。使用新的版本目录执行
`xshell-install.sh` 即可把旧 `socksctl` 替换为当前版本；不需要重装服务器或删除旧服务。

## 回退

本补丁只改变安装来源校验，不改变GOST配置格式。若安装前校验停止，服务器现有服务不会被
修改；若后续安装验收失败，仍使用既有事务快照和事件记录流程恢复。
