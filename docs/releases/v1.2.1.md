# v1.2.1 版本说明

发布日期：2026-08-11

状态：当前推荐稳定版

## 修改

- 新节点名称默认等于 VPS 公网 IPv4。
- macOS 部署不再要求 `--name`。
- Windows + Xshell 部署不再要求 `--name`。
- 仍保留可选 `--name`，用于无法自动获取公网 IP 等特殊情况。

## 新安装命令

macOS：

```bash
./deploy.sh root@VPS公网IP --port 31080
```

Windows + Xshell：

```bash
bash xshell-install.sh --port 31080
```

## 兼容性

- GOST 仍固定为 3.2.6。
- 默认端口仍为 `31080/TCP`。
- 已安装节点会保留原有名称和凭据，不会在升级时被自动改名。

## 回退

可以切换回 `v1.2.0`；已经运行的节点无需随脚本文档回退。

## 固定源码

发布后可通过 `https://github.com/wkx176617-sys/GIT/tree/v1.2.1` 查看。
