# v1.6.1 版本说明

发布日期：2026-08-12

## 版本目标

将 v1.6.0 的故障恢复能力收紧为“全面检测、克制维修”：原因明确且属于安全白名单时才自动
恢复；原因不足、端口冲突、外部网络或未知问题一律停止，记录事件并提供中文说明。

## 主要变化

- `socksctl heal` 采用严格白名单，不再根据任意本地非零诊断结果恢复快照。
- 白名单根因仅包括 `CONFIG_MISSING`、`CONFIG_PERMISSION`、`CONFIG_MISMATCH`。
- `SERVICE_DOWN` 与 `PORT_NOT_LISTENING` 只有作为明确配置故障的伴随现象时才允许恢复。
- `PORT_CONFLICT`、`DOCTOR_UNKNOWN`、单独服务停止及无法分类的结果会阻止自动维修。
- 诊断工具不再把凭据记录作为 Shell 代码载入；格式异常统一归类为 `CONFIG_INVALID` 并停止。
- `socksctl restart` 失败后只记录并停止，不猜测原因、不自动覆写配置。
- 新增 `socksctl report`，生成 root-only 脱敏报告，包含诊断、快照、事件和有限日志。
- 新增手动检查、维修与向 Codex 求助的中文教程和提问模板。

## 自动与手动边界

安装、升级和密码轮换仍属于事务操作：程序只回退自己刚刚进行的修改。日常运行故障则必须
通过维修白名单；白名单之外保持当前配置不变。用户仍可查看快照，并在理解影响后输入
`RESTORE` 手工恢复。

## 隐私说明

故障报告不读取 SSH 私钥，也不会主动输出节点凭据。它会使用保存的账号密码对日志做替换，
但日志可能包含用户自己手工写入的其他敏感内容，因此发送前必须人工检查。报告包含 VPS 公网
IP，只适合在私密求助中使用，不应提交到公开仓库。

## 兼容性

- Ubuntu 20.04、22.04、24.04
- `amd64`、`arm64`
- GOST `3.2.6`
- BBR 插件 1.1.0，仍为独立可选插件，主程序不会自动安装或启用

## 升级

切换到 `v1.6.1` 并重新执行原安装入口。程序会保留节点端口、名称和凭据；升级失败时使用
事务前快照恢复。升级后建议执行：

```bash
socksctl doctor
socksctl snapshots
socksctl report
```

确认报告可以生成后将其保留在服务器，需要求助时再查看和复制。
