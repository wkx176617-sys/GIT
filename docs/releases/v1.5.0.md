# v1.5.0 版本说明

发布日期：2026-08-12

状态：当前推荐稳定版

## 新增内容

- 新增独立可选的 BBR + FQ 插件 `addons/bbr/`，插件版本 `1.0.0`。
- 插件兼容主项目 `v1.4.0` 起的 `v1.x`，并随 `main` 的发布检查同步验证。
- `bbrctl status` 查看当前算法、队列规则和插件状态。
- `bbrctl check` 只读检查 Ubuntu、架构与内核 BBR 支持。
- `bbrctl enable` 保存原设置后启用并持久化 BBR + FQ。
- `bbrctl restore` 恢复首次启用前的算法和队列规则。
- 插件安装器默认不启用加速；必须由用户明确运行 `bbrctl enable`。

## 与主程序的隔离

- `deploy.sh`、`install.sh`、`xshell-install.sh`、`preflight.sh` 和 `overwrite.sh` 均不调用插件。
- 插件不开放端口，不修改 GOST 配置、节点 IP、SOCKS5 账号密码、萤光云安全组或旧 sing-box
  备份。
- 插件故障不会成为 SOCKS5 主程序的运行依赖。

## 兼容范围

- 主项目：`v1.4.0` 至所有 `v1.x`；未来 `v2.x` 需要重新验证。
- 插件系统：Ubuntu 20.04/22.04/24.04，`amd64/arm64`。
- Linux 内核必须已经提供 BBR；插件不会安装第三方或魔改内核。

## 使用方法

```bash
cd /root/socks5-toolkit/addons/bbr
bash install.sh
bbrctl check
bbrctl enable
```

恢复：

```bash
bbrctl restore
```

## 从 v1.4.0 升级

SOCKS5 主程序没有不兼容变化。切换到 `v1.5.0` 后，只有主动进入 `addons/bbr/` 安装并启用
插件，服务器网络算法才会改变。

## 回退

如果已经启用插件，切回旧标签前先执行 `bbrctl restore`，然后可以运行插件目录中的
`uninstall.sh`。仅切换 Git 标签不会自动恢复 sysctl 设置。

## 已知限制

- BBR 可能改善部分高延迟或丢包 TCP 线路，但不保证所有线路变快。
- 设置主要作用于新建立的 TCP 连接，测试时应重新连接客户端。
- 它不能改善 IP 信誉、住宅属性、DNS/WebRTC 隔离或 SOCKS5 加密。
- 若系统还有其他工具同时管理相同 sysctl 键，应先停止并确认其配置，避免互相覆盖。
