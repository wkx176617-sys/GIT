# v1.7.4 版本说明

发布日期：2026-08-13

## 版本目标

把“新手不应在庞大教学分支中迷路”从建议升级为强制规则，并用同一规则精简总路线、Mac和
Windows教程。专题可以完整，但每项操作只能有一个权威来源。

## 规则变化

- 新增“单一主路径，按需展开”：当前页面只展示当前步骤和一个推荐下一步。
- 平台、客户端、故障和插件各自只有一个权威教程，其他页面只链接，不复制操作。
- 迁移、升级、回退和加速必须放在首次成功主流程之后。
- 新增导航预算：总路线及每份平台教程不超过140行。
- 禁止通过压缩说明、堆叠命令或拆出无独立职责的文件规避预算。

## 教程精简

- 第一次搭建教程从约300行缩减为约100行，成为五步总路线。
- Windows教程只保留Xshell连接与安装，成功后统一进入客户端专题。
- Mac教程只保留Terminal、SSH和本地部署，成功后统一进入客户端专题。
- v2rayN、小火箭、比特浏览器、二维码和网络验收继续只在客户端专题维护。
- 故障恢复只在故障专题维护，BBR命令只在插件教程维护。

## 自动检查

发布检查新增：

- 三份新手路线的140行预算；
- Mac和Windows必须指向同一个客户端专题；
- 总路线和平台教程不得出现二维码或BBR启用、维修、恢复命令；
- 宗旨和仓库规则必须保留“单一主路径”边界。

## 复杂度与性能影响

- 常驻进程：无新增。
- 网络端口：无新增。
- 定时任务：无新增。
- 服务器依赖：无新增。
- 服务器运行逻辑：仅版本号变化，代理、诊断、恢复和插件逻辑不变。
- 用户步骤：主流程没有增加；可选内容延后，首次搭建需要阅读的分支显著减少。
- 模块耦合：运行模块无变化，文档之间的重复依赖减少。
- BBR 插件 1.1.0 保持独立可选，主程序不自动调用。

## 兼容性与升级

完全兼容 v1.7.3 和 v1.6.x 的命令、配置、凭据、快照、报告与插件。已有节点无需为了教程
精简重新部署；新手直接从 v1.7.4 第一次搭建总路线开始。

## 回退

本版本不改变服务器运行行为，通常无需回退。如需查看精简前的教程可切换 v1.7.3；旧教程
包含大量重复分支，不建议继续作为新手入口。
