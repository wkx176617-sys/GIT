# v1.7.5 版本说明

发布日期：2026-08-13

## 版本目标

让插件在 GitHub 主界面中有清晰、独立、可扩展的入口，同时明确插件不属于新手首次搭建主线。

## 插件中心

- GitHub首页新增“可选插件”模块，直接显示当前插件、版本、用途和入口。
- 新增 `addons/README.md` 作为全部稳定插件的统一登记页。
- 当前只有 BBR + FQ 1.1.0；未登记目录不视为稳定插件。
- 插件中心先说明“不确定时不安装”，再引导真实有需要的用户进入独立插件教程。

## 扩展规则

新增插件必须：

- 位于独立子目录并包含 `plugin.conf` 和 README；
- 声明版本与主程序兼容范围；
- 提供只读检查、明确启用、健康检查、恢复和卸载；
- 登记到插件中心；
- 不被主程序自动启用。

发布检查会扫描 `addons/*/plugin.conf`，阻止没有独立说明或没有登记入口的插件发布。

## 复杂度与性能影响

- 常驻进程：无新增。
- 网络端口：无新增。
- 定时任务：无新增。
- 服务器依赖：无新增。
- 服务器运行逻辑：仅版本号变化，代理、诊断、恢复和插件逻辑不变。
- 用户步骤：首次搭建无新增；需要插件时更容易找到唯一入口。
- 模块耦合：无新增；插件登记进一步强化独立边界。
- BBR 插件 1.1.0 保持独立可选，主程序不自动调用。

## 兼容性与升级

完全兼容 v1.7.4 和 v1.6.x 的命令、配置、凭据、快照、报告与插件。已有节点无需为界面调整
重新部署；GitHub 首页可以直接查看新插件模块。

## 回退

本版本不改变服务器行为，通常无需回退。如需查看旧首页可切换 v1.7.4；旧版仍可直接进入
`addons/bbr/`，但没有统一插件中心。
