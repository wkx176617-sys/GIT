# 轻量模块架构

## 模块关系

```text
客户端/比特浏览器
        │ SOCKS5 TCP
        ▼
GOST（唯一常驻业务进程）

按需管理层
├── deploy / xshell-install：单一智能入口和状态分流
├── preflight / overwrite：只读识别、受控旧协议迁移和失败回退
├── install：全新安装和本项目兼容升级
├── socksctl：统一命令入口和中文菜单
├── socks-doctor：只读或留档诊断
├── socks-safety：事件、快照、校验和恢复
├── socks-upgrade：已有本项目节点的稳定版本切换与健康快照降版
├── bbrctl：按需管理核心 BBR + FQ，保存原设置并支持恢复
└── uninstall：确认后卸载

独立扩展层
└── addons：当前为空，保留未来真正的非核心扩展入口

公开文档层（不连接 VPS）
└── 静态导航页：浏览器本地搜索公开教程，失效时回到仓库文字导航
```

## 模块边界

| 模块 | 负责 | 不负责 |
|---|---|---|
| GOST | SOCKS5 TCP 转发和认证 | 面板、报告、节点清单 |
| 智能入口 | 调用预检并分流到标准安装或白名单迁移 | 猜测混合状态、要求第二条覆写命令 |
| `preflight` | 只读识别空白、本项目、单一 sing-box 和未知/混合状态 | 停止服务、修改配置 |
| `overwrite` | 备份并停用单一旧 sing-box、轮换凭据、验收 GOST 独占端口、失败回退 | x-ui、Xray、v2ray 或未知程序迁移 |
| `install` | 原子安装、本项目兼容升级、验收、事务回退 | 日常持续监控、其他代理迁移 |
| `socksctl` | 用户入口、参数校验、调用明确模块 | 自己实现代理核心 |
| `socks-doctor` | 配置、服务、资源和有限外部检测 | 猜测外部原因、盲目维修 |
| `socks-safety` | 有限事件、快照校验和恢复 | 无限备份、云端同步 |
| `socks-upgrade` | 身份确认、版本比较、固定标签下载和健康快照降版 | 首次安装、任意旧包覆写、其他代理迁移 |
| `bbrctl` | BBR支持检查、冲突停止、启用、健康和恢复 | 替换内核、争抢其他sysctl来源、持续调度 |
| 插件 | 单一可选能力 | 修改主配置、自动接管主程序 |
| 平台教程 | Mac或Windows专属连接与部署步骤 | 重复维护客户端格式和完整原理 |
| 客户端教程 | 导入链接、二维码、浏览器配置和人工验收 | 安装或修改服务器服务 |
| 总路线 | 每一步只指向一个专题和下一步 | 复制平台、客户端、故障或插件细节 |
| 文档导航 | 返回、首页、静态搜索和文字后备入口 | 运行代理、读取凭据、形成第二套搭建流程 |

## 运行方式

正常工作时只有 GOST 常驻。其他脚本均为短时、按需执行：命令结束后不留下工作进程。项目不
安装数据库、消息队列、Web 管理服务、定时扫描器或集中调度器，因此 Mac/Windows 无需运行
本项目后台程序，低配 VPS 也不承担额外管理平台开销。公开导航由 GitHub Pages 托管静态文件，
只在用户打开页面时由浏览器读取公开教程索引。

## 扩展规则

新增插件必须包含：

- 独立目录、版本和兼容声明；
- 只读检查、明确启用、健康检查和恢复/卸载入口；
- 不由主安装器自动启用；
- 不读取或输出 SOCKS5 密码；
- 独立教程、版本说明和测试；
- 对 CPU、内存、磁盘、网络及常驻进程影响的说明。

需要跨越这些边界的设计，应先作为提案记录，不直接写入稳定分支。
