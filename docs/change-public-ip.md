# 同一台 VPS 更换公网 IP

本页只适用于：VPS 系统、磁盘和服务都不变，供应商只把旧公网 IPv4 更换为新公网 IPv4。
如果是更换整台服务器或重装系统，应重新走[第一次搭建总路线](tutorial.md)。

## 更换前

1. 关闭正在使用该节点的比特浏览器窗口和客户端。
2. 在供应商控制台完成公网 IP 更换。
3. 确认安全组仍保留 `22/TCP` 和 `31080/TCP`，来源仍是你的工作出口 IP `/32`。
4. 使用新 IP 重新登录 VPS：

```bash
ssh root@新公网IP
```

旧 SSH 会话中断是正常现象。

## 安全更新节点记录

登录新 IP 后运行：

```bash
socksctl refresh-ip --check
socksctl refresh-ip
```

第一行只检测和对比，不修改任何内容。确认显示的新 IP 与供应商分配一致后，再运行第二行。

程序会：

- 访问三个 HTTPS 检测目标，至少两个返回相同 IPv4 才继续；
- 显示旧 IP 和新 IP；
- 保留 `31080`、用户名和密码；
- 要求输入 `REFRESH-IP` 确认；
- 修改前建立事务快照；
- 更新节点名称、服务器记录、GOST 配置和服务说明；
- 重启、执行本地健康检查，并确认SOCKS5实际出口等于新公网IP；
- 失败时记录事件并尝试恢复修改前状态。

检测目标结果不一致、无法建立快照或记录格式异常时，程序不会修改节点。

## 更新客户端

成功后运行：

```bash
socksctl info
socksctl export
```

在比特浏览器、v2rayN 和小火箭中，把旧服务器地址替换成新 IP。端口、用户名和密码不变。
旧链接和旧二维码包含旧 IP，必须丢弃并重新复制或扫码。

## 重新验收

先运行：

```bash
socksctl check
```

再按[客户端导入与网络验收](clients.md)检查新 IP、DNS、WebRTC 和时区。全部通过前不要登录
业务账号。
