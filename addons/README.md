插件是首次搭建完成后的可选扩展，不属于 SOCKS5 主流程。主程序不会自动安装、启用、维修或
卸载插件；不确定是否需要时，保持不安装就是推荐选择。

## 当前插件

目前没有稳定插件。插件板块继续保留，未来只有真正独立、非核心且具备检查、恢复和卸载入口的
扩展才会登记在这里。

BBR + FQ 已从 `v1.12.0` 起成为主程序核心网络能力，使用方法见
[网络性能与核心 BBR](../docs/network-performance.md)，不再作为插件重复维护。

## 使用规则

1. 先完成[第一次搭建总路线](../docs/tutorial.md)和客户端验收。
2. 只有实际问题与插件“解决什么”一致时，才进入插件说明。
3. 先运行插件只读检查，再明确启用；不要把插件命令混入主安装流程。
4. 启用后使用插件自己的健康检查和恢复入口，SOCKS5 故障仍使用主程序故障教程。

插件必须独立提供版本、兼容范围、安装、检查、恢复和卸载说明。新增插件还必须在本页登记，
并通过主项目发布检查。
