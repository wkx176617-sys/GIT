# 可选插件中心

插件是首次搭建完成后的可选能力，不属于 SOCKS5 主流程。主程序不会自动安装、启用、维修或
卸载任何插件；不确定是否需要时，保持不安装就是推荐选择。

## 当前插件

| 插件 | 版本 | 状态 | 解决什么 | 不解决什么 | 入口 |
|---|---:|---|---|---|---|
| BBR + FQ | `1.1.1` | 可选、稳定 | 特定高延迟或丢包 TCP 线路的拥塞控制 | IP质量、DNS、WebRTC、加密和平台风控 | [查看说明](bbr/README.md) |

目前只有这一项插件。这里没有显示的目录不视为稳定插件。

## 使用规则

1. 先完成[第一次搭建总路线](../docs/tutorial.md)和客户端验收。
2. 只有实际问题与插件“解决什么”一致时，才进入插件说明。
3. 先运行插件只读检查，再明确启用；不要把插件命令混入主安装流程。
4. 启用后使用插件自己的健康检查和恢复入口，SOCKS5 故障仍使用主程序故障教程。

插件必须独立提供版本、兼容范围、安装、检查、恢复和卸载说明。新增插件还必须在本页登记，
并通过主项目发布检查。
